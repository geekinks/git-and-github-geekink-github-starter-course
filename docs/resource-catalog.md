# Audited training resource catalog

The following sibling repositories were available locally on 2026-10-30. They remain independent sources; `local_source` fields are audit provenance and are not expected to resolve after this repository is cloned alone.

| Local repository | Inspected focus | Course use |
|---|---|---|
| `01_skills-introduction-to-github/` | Four steps and event workflows for branches, commits, pull requests, and merging | Sessions 1 and 4 |
| `02_communicate-using-markdown/` | Headings, task lists, code, images, and merge workflow | Session 3 |
| `03_review-pull-requests/` | Review comments, suggestions, approval, and merge | Session 4 |
| `introduction-to-git/` | Codespace-based Git configuration, staging, commits, and history | Sessions 1 and 2 |
| `introduction-to-repository-management/` | Repository rules, collaboration files, healthy growth, and security preparation | Session 2 |
| `code-with-codespaces/` | Creating, configuring, using, and deleting a Python Codespace | Session 5 |
| `github-pages/` | Enabling Pages, configuring a theme, and customizing a site | Session 5 |
| `resolve-merge-conflicts/` | Creating, resolving, and committing a conflict resolution | Sessions 4 and 6 |
| `Advance/hello-github-actions/` | Workflow creation, triggers, jobs, and observation | Optional extension |
| `Advance/publish-docker-images/` | Container publishing workflow and package use | Future DevOps course |
| `ProJects/exercise-creator/` | Exercise structure, step design, triggers, workflow testing, and publication guidance | Course-authoring reference |

The resource workflows are purpose-built GitHub Skills state machines. They were not copied into the management repository because doing so would couple course content to administrative automation and grant unnecessary write permissions.
