# Git and GitHub Starter Course

This configuration defines six two-hour sessions delivered three times per week for two weeks. Cohorts provide actual dates and deadlines; this course definition stays reusable.

The local source repositories audited during migration are mapped in `docs/resource-catalog.md`. They remain separate repositories, so the course links to their upstream GitHub Skills exercises rather than copying them.

Completion requires approval of all six assignments, attendance at five sessions, and a final-project score of at least 70%. Automated checks only establish that mechanically verifiable requirements pass. An instructor must still approve the work.
