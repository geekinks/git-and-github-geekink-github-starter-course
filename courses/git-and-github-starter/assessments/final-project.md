# Final project assessment rubric

Maximum score: 100. The configured passing threshold is 70, and every criterion still requires instructor judgment.

| Criterion | Points |
|---|---:|
| Repository organization and appropriate files | 10 |
| Professional README with setup, usage, links, and clear writing | 20 |
| Meaningful Git history and commit messages | 15 |
| Feature branch and pull request workflow | 15 |
| Code review response and merge-conflict explanation | 15 |
| Local or Codespaces development evidence | 10 |
| Working GitHub Pages portfolio and deployment troubleshooting | 10 |
| Final reflection and ability to explain decisions | 5 |

Automated URL and file checks provide evidence only; they do not award rubric points automatically.
